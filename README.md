# PDF Bundle Builder

**A free desktop toolkit for working with PDF documents on Windows and macOS.**

PDF Bundle Builder brings everyday PDF tasks into one workspace. Merge documents, organize pages, add annotations, convert files, and prepare PDF bundles—all on your own computer.

🌐 **Website:** [ayushsingroul-collab.github.io/pdf-bundle-builder](https://ayushsingroul-collab.github.io/pdf-bundle-builder/)

## Features

- **Merge PDFs:** Combine multiple PDF files into one document.
- **Build PDF bundles:** Organize documents into sections with an index.
- **Organize pages:** Reorder, rotate, extract, and arrange PDF pages.
- **Annotate and sign:** Add notes, markups, and signatures.
- **Convert files:** Convert images to PDF, export PDF pages as images, and convert PDF to Word.
- **Compress PDFs:** Reduce file size for easier sharing.
- **Protect information:** Add password protection and redact sensitive content.
- **Work offline:** Process documents locally on your computer.

## Downloads

The Windows and macOS installers are currently being tested. Download links and system requirements will be published on the [website](https://ayushsingroul-collab.github.io/pdf-bundle-builder/) and in this repository’s **Releases** section when the builds are ready.

The first planned releases are for **Windows x64** and **macOS on Apple silicon**.

## Privacy

PDF Bundle Builder is designed to process your documents locally. Your files do not need to be uploaded to an online PDF service to use the app’s PDF tools.
